# To-Do Dashboard

A responsive To-Do Dashboard built with HTML, CSS, and JavaScript. The application helps users organise their daily activities by creating, updating, tracking, and managing tasks through a simple dashboard interface.

## Features

- **Add Tasks:** Create new tasks with a title, description, due date, and priority level.
- **Edit Tasks:** Update existing task information.
- **Delete Tasks:** Remove tasks that are no longer needed.
- **Task Management:** Move tasks between To Start, In Progress, and Completed.
- **Search Tasks:** Find tasks using keywords.
- **Date Filtering:** Filter tasks by today, this week, or all dates.
- **Priority Levels:** Assign Low, Medium, or High priority to tasks.
- **Local Storage:** Save tasks in the browser so they remain available after refreshing the page.
- **Responsive Design:** Access the dashboard on desktop, tablet, and mobile devices.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.
4. Start creating and managing your tasks.
